# LL-autogen-demo

#### Overview
This repository contains a mock file that shows a very simple example on how to create agents. 
It also contains a demo on four agents working together to create a budget and itinerary for a vacation. 

#### Ensure to create virtual environment:
- python -m venv .venv
- .venv\Scripts\activate  
- pip install -r requirements.txt
- In order to run a python file using an open model client you will 
need two environment variables that contain the endpoint and key.
- Run the python file
